# Acoustic Echo Cancellation

MATLAB implementations for four experiments:

1. LMS with white-noise input and three step sizes
2. LMS versus NLMS with speech input
3. NLMS versus RLS with speech input
4. NLMS versus F-NLMS with a 1024-tap echo path

## How to run

Use MATLAB R2017b or newer.

Place the required course data files in a data folder beside
the scripts. Open each script and click Run.
